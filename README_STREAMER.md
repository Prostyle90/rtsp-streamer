# Desktop Streamer

Локальная трансляция выбранного монитора по RTSP без облачного сервиса.

Поддерживаются основной и опциональный субпоток. Для основного потока доступны исходное разрешение и 720p. Для субпотока доступны CIF и VGA, по умолчанию используется CIF. Выбранный микрофон передаётся одновременно в оба потока в формате G.711 μ-law (PCMU), 8 кГц, моно, 64 кбит/с.

Разрешение, субпоток и звук можно менять во время работы. Программа автоматически и безопасно перезапускает медиапоток с новыми параметрами; повторно нажимать кнопку запуска не требуется.

Доступны три режима аудио: только выбранный микрофон, только выходной звук ПК и одновременное смешивание микрофона со звуком ПК. USB- и JACK-микрофоны выбираются из списка DirectShow. Звук ПК захватывается с устройства воспроизведения Windows по умолчанию встроенным loopback-компонентом.

## Запуск

Откройте `DesktopStreamer.exe`, выберите монитор, разрешение и звук, затем нажмите «Запустить поток». Кнопка `EN/RU` в верхней части окна переключает язык, а кнопка «Справка/Help» показывает краткое описание возможностей.

Используйте именно `dist\DesktopStreamer.exe`. Это нативная Windows-версия, ей не нужен Python.

Поток доступен в VLC или другом RTSP-плеере по адресу, указанному в окне. Вместо `<адрес компьютера>` укажите IP компьютера в локальной сети.

Для подключения с другого устройства разрешите входящие подключения к выбранному TCP-порту в брандмауэре Windows. По умолчанию используется порт `8554`.

## Ограничения

- Захват звука зависит от устройств DirectShow, установленных в Windows.
- Для системного звука нужен источник вроде Stereo Mix или виртуального аудиокабеля.
- Захватывается только весь выбранный монитор; режим отдельных окон удалён.

## Комплект для GitHub Releases

В архиве `DesktopStreamer-Windows.zip` уже находятся `DesktopStreamer.exe`, `AudioLoopback.exe`, `ffmpeg.exe` и `mediamtx.exe`. Дополнительные пакеты Python, FFmpeg или MediaMTX устанавливать не нужно. Программа использует системный .NET Framework 4.x (компонент Windows 10/11); отдельный установщик для него обычно не требуется.

Инструкция по пересборке находится в `BUILD.md`.

При сворачивании окно скрывается в системный трей; двойной щелчок по значку восстанавливает его. Логи работы: `desktopstreamer.log`, `streamer_ffmpeg.log`, `streamer_mediamtx.log`.
